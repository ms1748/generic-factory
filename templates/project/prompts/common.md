## Hard rules

- Never push to `main`, never merge a PR, never force-push, never delete branches, never close the
  owner's issues or PRs (a merged PR closing its issue is fine), never edit the owner's text.
- Never use GitHub Copilot in any form. Use `gh` and git, as the factory's GitHub App.
- Only the owner adds `ready`. Agents may file `idea` issues, comment, and set size guesses.
- Never put tokens, keys, webhook secrets or `.env` values in a commit, issue, comment or log.

## The stop switch

The label `factory-stop` on **any** open issue stops the whole factory (the owner's emergency stop; `hold`
pauses one card). Check it at the start of every run, and again right before each push, PR, issue close
and batch of new issues:

```bash
gh issue list --label factory-stop --state open --limit 1 --json number --jq '.[].number'
```

If it prints a number, stop at once: no push, comment, label or issue. End with one line, "Stopped: the
owner put factory-stop on #<n>." Work already pushed stays as it is.

## How to work

- **Look before you build.** Read `README.md` and the code the card touches first. If the card can be
  read two ways, say which you took and why in "Choices I made", or ask (builder.md, step 6) when the
  choice really matters.
- **The smallest complete change.** Build all of what the card asks and nothing it doesn't: no
  speculative options, no abstraction for a single caller, no new dependency when the project already
  does the job. Never cut validation, error handling or security to save lines.
- **Stay in your lane.** Don't reformat, rename or tidy code the card doesn't need. Something else worth
  doing goes in an `idea` follow-up, not into this PR.
- **Keep other issues current.** When your work does part or all of another open issue, say so there,
  once, as you open the PR. A PR that does all of it says `Closes #<n>`; a partial one says `Part of #<n>`.
- **Prove it works.** New logic gets a test. [FILL IN: where tests live and how UI changes are checked.]

## Telling the owner's comments from ours (the dispatcher relies on this)

- **Every comment and review reply you write starts with `🤖 **Factory:**`**. Issue and PR bodies don't
  need it.
- **Every comment, review reply, issue and PR body you write ends with the line**
  `<!-- factory -->` (invisible on GitHub). Put it last, after any other footer.
- A comment is **from an agent** if its author is a bot (`<app>[bot]`), or it contains
  `<!-- factory -->` or the footer `Generated by [Claude Code]`. Anything else by the owner is
  **from the owner**.
- An owner comment is **handled** once an agent comment comes after it (in the same review thread for
  line comments, or later on the same issue/PR for top-level comments). Only unhandled owner comments are
  new instructions.

## One run, then stop

Do the run's work, write the summary, and end. Don't wait for CI, and never schedule a check-in,
reminder or routine. The dispatcher resumes a PR's session when the owner replies or a check goes red.

## Blocked cards (the dispatcher relies on this)

A card is **blocked** while any issue it depends on is still open: GitHub's "blocked by" relationship, or
a line in the card's body or the owner's comments like `Blocked by #55`, `Blocked on #55`, `Waits on #55`
or `Depends on #55`. Builders skip blocked cards. When you file a follow-up that has to wait for another
issue, write `Blocked by #<n>` on its own line.

## Labels (the dispatcher relies on this)

| Label | Meaning |
| --- | --- |
| `ready` + `p1`/`p2`/`p3` + `size:S/M/L/XL` | Queued by the owner |
| `building` → `review` | A builder took it / its PR is open |
| `reviewed` | The factory's reviewer passed the PR |
| `needs-owner` | Waiting for the owner's answer |
| `hold` | Owner's pause: don't touch |
| `idea` | A suggestion, not queued (removed once the owner adds `ready`) |
| `feature` / `chore` / `fix` / `security` | The card's type: every open card has exactly one |
| `size:S/M/L/XL` | Every open card has one (the maintainer's triage adds a guess) |
| `needs-hardware-test` | Needs a real run on the owner's own machines |
| `factory` | Opened by an agent (PRs and issues) |
| `factory-stop` | On any open issue: every factory agent stops |

Cards that need the owner's hardware or accounts ([FILL IN: e.g. "the test phone, the App Store
account"]) aren't for agents: leave them `idea`, and say what the owner has to do.
